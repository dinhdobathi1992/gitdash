Eight phases, one checkpoint.

    User flowOrg mode, after phase 5

    What happens on every request.

    1. Public path? Matched by whole segment, so /docsX is not public. Pass through.
    2. Cross-site write? Non-GET to /api with a foreign Origin gets 403.
    3. Who is this? whoami(token) calls GitHub /user with the token in use, cached 60s, and checks allowed-org membership. The cookie is never trusted for identity.
    4. What may they do? Groups from the DB plus env bootstrap admins. Flags are the union of group grants. Cached 60s.
    5. Decide. Admin routes always enforced. With enforcement off, everything else behaves as today.
    6. Infra down? Last known answer for up to 10 minutes, then 503 authz_unavailable. Never a login redirect, never fail open.
    request → proxy.ts (Node runtime)
  ├─ public (segment match) ─────────→ next()
  ├─ non-GET, foreign Origin ────────→ 403
  ├─ token? no ──────────────────────→ /login | 401
  ├─ whoami(token)   [L1 60s]
  │    401            → clear → /login
  │    not in org     → 403
  │    5xx / timeout  → last-known ≤10m | 503
  ├─ resolveAccess(id) [L1 60s → DB]
  ├─ decide(classify(path), access, ENFORCE)
  │    no groups      → /pending | 403 no_groups
  │    unregistered   → 403
  │    not granted    → / | 403 forbidden
  └─ handler → withCache: L1 → L2(shared) → GitHub

    DecisionsConfirmed by Thi

    Settled before any code.

    TopicDecision

    Permissions gate GitDash surfaces, not GitHub access. Where GitDash serves data synced with its own token, the plan checks the user's own token first.

    Risk and reviewRed team 2026-09-27

    What the red team caught.

    Accepted risks.

    Proxy cannot import db or cache

    Phase 5 step 1 checks the Next 16.3 docs first. Fallback: requireAccess() in every non-public handler with the same decide().

    Per-instance login rate limiter

    Accepted and documented. Allowed-orgs and the group requirement remove most of the abuse value.

    Cached GitHub data at rest in Postgres

    Opt-in GitHub routes only, token-scoped keys, TTL with delete-on-read and sampled purge.

    Stale grants for up to 60s

    This is the documented contract. Up to 10 minutes only while the DB or GitHub is unavailable.

    None. All questions were resolved in the red team and validation sessions.
